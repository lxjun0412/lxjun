### Spider and Grils

一：
这是一次郊游，学校极少举办的外出活动，小玲自然是很兴奋的，她和班里大多数女生一样，都是普通女孩，面对极少数的外出郊游的机会，她自然是很期待的。
这次，学校六年级的四个班到了一个草地上，旁边有一处密林，这时候，一个同学在一个四个班大多数同学都进了的微信群里发了条消息：“要不咱去树林里探险一下？”，自然，下面一片“好”，“没问题”，“OK”，小玲自然也回了。
但是在他们进入树林并到达深处的一片空地后，可怕的事发生了

“诶？你们有没有听到窸窸窣窣的声音？”小妍忽然问。小玲仔细一听，好像还真的有，他们一行人只当是什么动物，没在意。

但当时间一长，而窸窣的声音一直断断续续的出现，但他们只能假装没发现，虽然心里也在发毛，比较自我安慰是很重要的。

突然，一只蜘蛛出现在他们面前，挡住了他们的去路，因为那只蜘蛛有一头小象那么大，大家都被吓出了惊叫，那只蜘蛛突然射出几条蛛丝，把几个男生一次性裹住甩到一边，小蔓是这批女生里反应最快的，她双马尾一甩，转头就跑出老远，而小玲她们几个就没那么幸运了，她们一个个的被蛛丝裹住，倒在地上，接着蜘蛛一个接一个的，在她们的后脖颈上咬了一下，很轻，但蜘蛛的螯是有毒的，她们马上昏迷了过去，小玲只看到蜘蛛朝着小蔓逃跑的方向离开，接着就失去了意识。

等小玲再醒来时，她已经在一个山洞里了，后颈上的咬痕还在隐隐作痛。所有没逃走的女生都在这，她们靠墙坐着，双手被用蛛丝绑在身后，脚踝也被捆住，挪不得位置，但还能互相对话。
“你们说，小蔓逃出去了吗?”，小冰问
“都什么时候了你还担心她？为什么她就自己一个人跑出去”，小瑶的语气里带着一丝不满。
“你们觉得我出去了吗？”，是小蔓说的，但声音很怪，像耳语，但声音却和正常人的一样大，像是蜘蛛的嘶嘶声。所有人猛的回头，发现小蔓正坐在那里，穿着学校的秋季校服，扎着双马尾，但脸色惨白，甚至有些发青，她没有被绑着，当小玲的目光扫到她的手上时，她倒抽了一口凉气：“小蔓，你……”
那双手，不是她所记得的人手，现在那部分的结构如同蜘蛛腿，覆盖着绒毛，不注意看，还以为是一双带毛的手套。
“是的”，小蔓回答，她站起来，深深鞠了一个躬：“对不起，我没能叫人过来救你们出去”
原来小蔓并不是逃跑，而是去求救，但很不幸，她还是被蜘蛛抓住了。
“而且这双手……”她看着那十根如同蜘蛛腿的手指，“可能再也按不了琴键了”小蔓现在声音里带着点哽咽
小玲明白，小蔓和她是同学，可为多才多艺，会舞蹈，会弹琴，会声乐，而且文化科也极好，还会打羽毛球，失去最得意的才艺，对一个艺人来说，比死还痛苦。
这时，小妍慢慢蹭到小蔓身边，她说小玲的同班同学，也是班长，马尾辫随着她一点点的挪动而一甩一甩
“小蔓，没事的”她轻声在小蔓耳边说，“无论你变成什么样，我们都还是同学，对吗？”
小蔓把头埋在手里，用那种怪异的，带着“嘶嘶”的底噪的声音回答了一声“是”，小妍接着说：“无论如何，我们都在一起，不是吗？我们不会因为你的变化而把你抛开，我们还是一起的”
小蔓慢慢把头抬了起来，转头看着小妍，“谢谢”，虽然嘶嘶声没有语气，但小玲还是听出了其中的感激。
良久的沉默。
“诶对了，小蔓，你是怎么变成这幅摸样的”小瑶的一句话打破了这种宁静，小冰马上转头看着她，麻花辫轻轻拂过小玲的后颈，碰到了那个咬伤，“你能不能不要老是哪壶不开提哪壶”，小蔓摆了摆手：“没事，她就这样，什么都记得住但就是记不住啥时候该闭嘴，我说了也没什么问题”
原来，虽然小蔓跑了，但是蜘蛛比她更快，最终她还是被追上了。
“它（蜘蛛）把我抓住后，在我两个手腕上都咬了一口，可能是怕我逃跑，它把我用蛛丝裹住全身，我动不了，本来我以为，它只是想束缚住我，让我动不了，等待毒发，接着，我发现，那些蛛丝不但限制我的行动，而且，末端还插进了我的体内，那些蛛丝……在吸我的血……”
小玲忍不住看了看小妍脚踝上的蛛丝，果然，那些蛛丝的末端扎在她的脚踝上，边缘发青，她知道，她自己身上的蛛丝也是这样的。
“它在等蛛丝把我的血抽离一些，来让蛛毒占据我的身体，接着我就感觉手腕上的伤口开始作痛，接着我感觉从手腕处开始，我的手开始变化……那个过程……”小蔓停了一下，似乎在回味当时的感受，“真的，很痛，我手上的肌肉在一点点的被几丁质取代，是粗暴的代替，特别疼
“同时，我感觉喉咙也在作痛，在里面，我的声带也在变，所以你们现在听到我的声音就成了这样。我知道，变化不止这些，我现在身上有一部分是人的，而另一部分是蜘蛛的……”声音还是那种带着蜘蛛嘶嘶声的音色，但在“我现在身上有一部分是人的，而另一部分是蜘蛛的”这里时，小玲听出了一种小蔓强烈抑制的颤音，她很痛苦，但不想让她们知道，小蔓不想让她们为她而更加痛苦。

忽然，小冰轻轻叫了一声，小玲回头，“小冰，你怎么了？”，小冰摇摇头，脸色有些白，表情看起来有点想吐：“没事……就是……有些……晕。”，她的声音变了一些，带着一点嘶嘶的底噪，但大体还是人声，小蔓走上前，把那双如同蛛腿的手，抓住小冰脚踝上的蛛丝，一拉，蛛丝断开，“这些蛛丝……能吸血，你体质比较差，可能有些受不了”，接着小蔓一个接一个的，把她们身上的蛛丝都解开了，“你为什么现在才解？”小瑶问，“说了不要哪壶不开提哪壶”，小冰轻声说，她现在正倚在小妍腿上，有些虚弱。

等小冰的身体缓和了一些，她们决定离开，这时，小蔓突然停住，小玲也感受到了
蜘蛛的震动
“它来了，快走”小蔓说，推了小玲一下
“要走就一起走”，小玲抓住小蔓的手，冷冰冰的，但绒毛依然积蓄了一丝体温，相比于这个山洞，还是比较暖和的。
小蔓虽然试图把手挣开，但小玲抓的很紧：“没事，虽然他们可能接受不了你，但我们会”，说罢就拉着小蔓跑起来。

她们已经快到树林边缘，那只蜘蛛突然出现在道路中间，向她们吐出一道蛛丝，小蔓的手被小玲拉着，这时她立马挣开然后躲到一边，小玲推了一把小冰让她不会被碰到，但小玲自己没来得及闪开，她的胸口被蛛丝射中了，接着她感到一股强大的拉力把她往蜘蛛那边拉，同时身上的蛛丝开始从胸口扩散到全身，就在她离蜘蛛只有三四米的时候，小蔓滑步过来，用她那覆盖着几丁质的手，把蛛丝割断了，小玲马上把身上蛛丝扯下来，因为这东西会吸血。但这时蜘蛛已经把把小蔓咬住，她拼命的击打着蜘蛛的头部，但即便是她的手，也伤不了那蜘蛛分毫，她试图把螯掰开，但也无济于事，在被普通蜘蛛大数倍的狼蛛的螯的力气面前，她的手部力量微不足道。小玲和小妍想跑过去，但很快被蛛丝拦下，但这时，小蔓突然发出一种极其怪异的声音，小玲听不懂，那是一种蜘蛛的嘶嘶声，接着，蜘蛛僵住了，然后慢慢把小蔓放下，接着离开了。蜘蛛走后，小蔓坐在地上，捂着脸，好像在哭。小玲明白，虽然会说蜘蛛的语言救了她，但是这也让小蔓离她原来的那个身份——一个完整的，手上没有几丁质的，声音不带嘶嘶声的——人，又远了一点。
“小蔓，没事的，我们和你一起。”小冰上前，拍了拍小蔓的肩膀，“我们走吧。”“嗯，走吧”，小蔓站起来，声音里带着哽咽。
“另外……谢谢”小瑶轻声说，小蔓回头：“谢什么？”“谢谢你救了我们。”

二：
她们走出来树林，外面依然很明亮，同学们的欢笑声、嬉闹声如常，仿佛什么也没发生过，但后颈的伤提醒着小玲，什么都发生过了。
“小玲、小妍！你们回来了！”是小萍，和她们同行去探险并被蜘蛛俘虏的一个女生，她冲过来，后面跟着小菲、小静和小琪，“嗯”，小玲点点头，“你们怎么出来的？”小萍想了想：“山洞里一个女生帮我们把蛛丝解开让我们走的，她的样子，和现在的小蔓……一模一样”小蔓这时走了过来，“那她现在呢？”“她说……她已经在这被关的太久了，离不开了。”小玲点了点头，“没事就好”“可……小蔓她……”“被蜘蛛咬了”“哦”小萍知道，有些东西，虽然人人都知道，但问出来，还是伤人的。

回程时，已是夜晚，大巴上，小瑶正和小琪谈着她们的经历，小冰靠在小妍腿上，已经睡着了，小妍轻轻的拍着她的背。小玲坐在靠窗的位置，小蔓在她身边，她们没怎么说话，小玲在思考关于那个救了小萍她们的女生的事，她是谁？为什么要救她们？为什么她不尝试离开呢？，小蔓则在端祥着她那十根如同蜘蛛腿的手指，一言不发，周围的人看到她的手，都在窃窃私语，小玲听不到他们在说什么，但小蔓已经快哭出来了，蜘蛛对震动的敏感，有时是优势，比如危险来临时，总能第一时间发现；有时是劣势，比如在别人悄悄谈论她时，她不得不听到他们谈论的内容。

“小蔓？”小玲轻声问，小蔓没说话，而是抬起头，看着小玲，乌黑的头发，苍白的面容，但眼睛，还是小玲认识的那双眼睛，柔和，坚强，还有一丝不认输的倔强。“你……还好吗？”小蔓点了点头，她不想说话，因为她一张嘴就可能控制不住，哭出来，如果她是正常人，现在眼泪已经流出来了，可是现在她的身体，已经产不出眼泪了，这有时是好事，比如在情绪受损时，可以更好的掩藏；有时是坏事，比如在情绪失控时，欲哭无泪，是最痛苦的。

小蔓突然转头看向后面的那辆大巴：“她在后面。”“她……谁？”“救小萍她们的人”小蔓伸出手指，用指关节轻轻敲着座椅扶手，那种敲击很有节奏，像是……一种信号，“你在做什么？”“跟她说话”小蔓笑了一下，乌黑的头发，苍白的面容，但这个笑，还是小玲认识的那个笑，亲切，温和，带些受表扬后的骄傲，“我在和她沟通”“你跟她说什么了？”“我和她说，谢谢。”

巴士驶入城区，霓虹灯的光闪烁着，小蔓的手在动，像在写字，“你在写什么？”“我在写……‘家’”小玲把手放在小蔓的手上，：“对，回家了”，那五条蜘蛛腿……不对，是五根手指，轻轻的，轻轻的，回握住小玲的手。

第二天去学校，小玲径直到了琴房，里面传出短短续续的琴声，小玲不懂钢琴，也不知道这是什么曲子，她走进去，和她猜的一样，小蔓正坐在钢琴前，她在尝试，虽然调子有些怪，因为几丁质在常温下不会变软，小蔓只能用坚硬的之间去敲着琴键，但依然很悦耳。

课间，小彤找到小蔓，手里拿着球拍：“小蔓，打羽毛球吗？”，小蔓点了点头，虽然她可能拿不住拍了，但小彤这个邀请，是除了那七个被蜘蛛掳走的女孩外，唯一一个同学愿意与她连接。

球场里，小蔓的表现超出了小玲的预期，她自己也一脸兴奋，因为，她的手——那双如蛛腿的手，还能握住球拍，虽然她失去了一些东西，但……她的价值还在。

日复一日，小蔓依然能感受到周围的同学在说些什么，但她的钢琴技法也渐渐恢复，她开始学着掩盖声音里那股嘶嘶声，很明显，这很成功，现在，虽然她的皮肤依然惨白，手依然如同蜘蛛腿，但声音已经和常人差不多，甚至能重新上台歌唱。每天下午放学后，在晚自习前的窗口期，她总会和小彤去到球场打羽毛球，小彤是班里体育最好的女生，在小蔓变化之前和小蔓总是如姐妹般亲近（当然小蔓变化之后也是这样的）。
